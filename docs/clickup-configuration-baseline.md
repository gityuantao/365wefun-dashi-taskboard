## 状态（2026-08-05 已新增缺口）

### 任务（正式与 Sandbox 一致）

`收件箱` → `分析中` → `待开发` → `开发中` → `待测试` → `测试中` → `待验收` → `验收中` → `待发布` → `已发布`

终态：`已取消`、`已发布`。

本次新增：`验收中`（此前缺失）。状态顺序已按主流程排列（2026-08-05 调整）。

### 版本（正式与 Sandbox 一致）

`规划中` → `进行中` → `待发布` → `发布中` → `已发布`

失败回路：`发布中` → `发布失败` → `发布中`（原样重试）或 → `进行中`（需要变化）。

终态：`已取消`、`已发布`。

本次新增：`发布中`、`发布失败`（此前缺失）。状态顺序已按主流程排列（2026-08-05 调整）。

> 说明：Sandbox 列表同时存在 ClickUp 强制内置状态 `to do` / `in progress` / `complete`，按既有规格约定保留为未使用的系统备用状态。
